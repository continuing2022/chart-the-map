# 决议：确定私密云端数据边界与合规要求

## Resolution

MVP 采用境内最小化云端处理：仅保存 `openid` 与内部用户 ID、原图及其必要元数据、风格图、营养估算和短期任务状态；不获取头像、昵称、手机号，不将照片或营养记录用于训练、广告或画像。

- `wx.login` 的一次性 code 只发送到自有后端兑换身份；`session_key` 不得下发客户端或提供给第三方，见[微信登录文档](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)。
- 调用相机/选图前，按微信隐私规则明示收集目的并取得授权，见[小程序隐私保护指引](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)。
- 照片上传前剥离 EXIF/GPS；自有后端以私有对象存储、强制用户鉴权、短时签名 URL、传输与静态加密处理数据。风格图和营养估算均随原餐食删除。
- 对象存储选用[阿里云 OSS](https://oss.console.aliyun.com/overview)：上线配置须锁定中国大陆地域的私有 Bucket，禁止公共读写；客户端不持有长期凭证，所有上传、访问、导出和删除均由自有后端按当前用户授权。原图和风格图应以同一餐食的删除任务联动清除。
- 设置页提供导出、删除单餐和彻底删除全部数据；建议在线数据 24 小时内清理、备份以用户专属密钥销毁并在 30 天内淘汰，实际 SLA 需按架构和供应商合同确认。
- 仅选用境内 AI 和存储服务；供应商作为受托方，合同限制处理目的、地域、留存、训练、转委托、删除证明和安全事件通知。向境外服务传输图片、身份或营养数据不纳入 MVP。
- 风格图在页面和导出物中保留 AI 标识；上线前须由法务确认实际责任分工。依据包括[《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)和[《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)。这不是法律意见。
