# AI 饮食日记｜低保真原型 01

这是用于讨论信息层级与操作路径的文字线框图，不代表最终视觉样式。

## 视觉方向

采用 Apple 系统界面般清晰、克制、重留白的层级：轻背景、圆角卡片、简洁图标和细腻状态动效。餐食的趣味感由少量贴纸点缀与 AI 风格图承担，而非重度游戏化装饰；不使用 Apple 商标、图标或专有界面资产。

## 2. 餐食详情

```text
┌──────────────────────────────────┐
│  ‹ 返回                 早餐 · 9/8 │
│                                  │
│  ┌────────────────────────────┐  │
│  │       AI 风格化餐食图        │  │
│  └────────────────────────────┘  │
│  [AI 风格化]      查看原始照片    │
│                                  │
│  一句话记下这一餐…                 │
│  第一次吃这家豆浆，意外很香。       │
│                                  │
│  营养估算                  编辑 › │
│  豆浆（标准）  油条（标准）         │
│  约 420 kcal                     │
│  蛋白质 14g · 脂肪 18g · 碳水 51g │
│  图片与份量推算，仅供记录参考       │
│                                  │
│  ⋯ 重新生成风格图       删除此餐    │
└──────────────────────────────────┘
```

“编辑”进入轻量清单：可新增、删除、改名菜品，并将每项份量设为少/标准/多；保存后立即重算营养。原图、风格图和营养任务各有独立重试与删除结果。
