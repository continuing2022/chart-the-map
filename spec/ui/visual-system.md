# 食光日记 · 视觉系统

本次仅调整五个现有页面的 WXML、WXSS、导航配色及本地图标。餐食保存、补记、替换、删除、异步生成、备注、回顾与默认风格选择沿用现有方法与数据。仅同步了详情页原生确认弹窗的按钮色值；未修改业务逻辑、服务端或数据结构。

## 基础规范

统一定义见 `styles/design-system.wxss`。全局从 `app.wxss` 引入；独立样式隔离的品牌导航和 TabBar 分别引入相同文件。

| 项目 | 规范（375px 设计基准） |
| --- | --- |
| 背景 | `#FAF8F4` 暖白 |
| 内容表面 | `#FFF9F3` |
| 品牌色 | `#EF625E`；浅底 `#FCE3E0` |
| 文字 | 主文字 `#1F1F1F`，辅助 `#74716E`，弱文字 `#AAA5A0` |
| 记录成功 | `#72B98B`，同时显示文字状态 |
| 错误 / 删除 | `#E8645C`，与品牌 CTA 分开使用 |
| 暖橙点缀 | `#F4A340`，仅少量太阳、星光与生活感强调 |
| Glass Card | `rgba(255,255,255,0.72)` |
| 分隔线 | `rgba(60,45,35,0.08)` |
| 字体 | 系统无衬线；仅品牌与少量情绪文案使用楷体回退 |
| 一级 / 二级 / 卡片 / 正文 / 辅助 | 30 / 20 / 16 / 14 / 12px |
| 页面边距 / 模块间距 / 内容间距 | 22 / 24 / 12px |
| 卡片 / 图片 / 按钮圆角 | 20 / 16 / 16px；胶囊 999rpx |
| 主要按钮 | 44px 基准高度，最小触控高度 44px |
| 图片 | 首页与日历统一方形；四餐回顾使用方形网格；详情主图为 34vh，按页面要求独立控制 |
| 阴影 | 普通餐卡无阴影；浮动玻璃使用低透明柔和阴影 |

视觉比例以 **70% 暖白/奶油背景 + 20% 黑灰文字与照片 + 10% 品牌及状态色** 为方向；照片数量由真实记录决定，不对照片强行染色。品牌红仅用于主按钮、当前 Tab、选中状态和少量强调，不用于页面大底。

rpx 随屏宽缩放；导航、月份箭头、返回、编辑、更多及主要按钮保留实际像素的最小点击面积。底部 TabBar 留出安全区，首页和日历有足够滚动尾部空间。

## 页面应用

- **首页**：品牌缩小、去下划线；日期使用系统黑体；状态文字保留完整的完成、生成中、失败和模拟信息。四餐双列按内容自然增高，不再依靠固定视口高度撑开或裁切。昨日回顾使用实际上一日记录图片，缩为横向轻玻璃模块。
- **日历**：一级标题与品牌区分；月份切换使用玻璃胶囊。日期使用无外层卡片的时间线；四餐方形缩略图与低对比空位有明确层级，回顾入口保留在日期行。
- **详情**：返回导航后依次呈现餐名、日期、34vh 主图、图片切换、生成状态、小记与操作栏。操作栏随内容排列，长备注和失败说明可正常滚动。原图/风格图状态、失败重试、替换与删除确认沿用现有逻辑。
- **回顾**：去除照片外层厚重卡片及胶带，四餐采用 2×2 网格；一至三餐按原记录数量展示，并保留情绪文字。统计改为单行，只保留一个珊瑚红主按钮，返回为文字按钮。
- **设置**：风格预览为三个同尺寸小卡片，当前选择为细珊瑚红边框和勾选。隐私与数据合并为单一分组列表，行间使用细分隔线。原有说明入口保留；无操作的说明行不添加虚假的导航箭头。

## Glass 与兼容性

玻璃仅用于导航控件、TabBar、月份切换、昨日回顾、图片标签、分段切换和操作栏。未对所有餐卡应用模糊。半透明暖白本身足够阅读，不支持 `backdrop-filter` 的客户端会显示半透明表面与细边框，不影响操作。

SVG 图标采用同一 24×24 画布、1.7 线宽和圆角端点；已选中导航使用品牌色，删除图标使用 Danger 色。风格预览中的猫、小熊和人物属于内容示例，不属于导航图标。

## 已完成 UI Audit

- 五页均使用同一边距、颜色和圆角基础，设置页的原生导航背景也已对齐。
- 品牌 16px，页面标题 30px；移除重复书法标题与粉色下划线。
- 普通卡片不使用玻璃、明显阴影或嵌套描边；日历不再按天套卡片。
- 去除大面积渐变、纸纹及重复花朵、胶带、星星。仅保留少量品牌情绪。
- 图片占据主要视觉；无记录空位降低色彩和图标权重。
- 详情与回顾不再用固定高度、固定底栏或巨大底部 padding 制造内容空白。
- 页面所有绑定事件均对应现有方法；未新增业务入口。
- 微信开发者工具内置 **WXML 与 WXSS 编译器**对全部页面及共享组件编译通过。
- `npm run check` 通过；现有 **52 项回归测试**全部通过。旧导航测试中“必须 flex:1 撑满视口”的断言改为检查自然滚动、无固定页面高度、无页面裁切；其余交互测试保留。
- 对实际 WXML/WXSS 的浏览器投影检查了 **320、375、430px** 下的 **33 种状态**，涵盖空记录、混合记录、风格生成中/失败与一餐/三餐/四餐回顾；无横向溢出、无图片缺失。

浏览器投影使用示例数据及项目已有餐食素材，不是微信真机截图。尚未执行 iOS / Android 微信真机验收；实际字体、系统胶囊、安全区、键盘与玻璃模糊效果应以微信客户端为准。
